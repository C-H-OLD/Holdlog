# Holdlog

클라이밍 크루의 일정과 개인·공동 운동 기록을 관리하는 iOS·Android 앱이다. 암장·브랜드·세팅 데이터는 별도 관리자 웹에서 관리한다.

## 현재 단계

문서와 Figma 시안을 준비했고, GitHub Spec Kit·Codex·Living Spec 개발 방식을 설정했다. 공통 workspace·계약 생성과 서버·DB·worker·관리자 웹 실행 기반을 구현하고 로컬 단독 검사를 수행했다. 모바일 기반과 iOS/Android 전용 앱 실행도 확인했으며 실제 연동은 남아 있다. 설치·실행 방법은 개발 시작 안내에서 확인한다.
