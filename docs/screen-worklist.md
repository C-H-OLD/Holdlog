# 앞으로 만들 화면 목록

정리일: 2026-10-07

## 현재 상태

통계 상단·기간 배치·빈 기간 문구 수정과 알림 목록05.07 추가는 사용자 확정 내용이다. [현재 화면 설계](./screen-design.md#screen-05-07)·[수신/읽음 규칙](./functional-spec.md#notification-inbox)을 반영했다. Figma에서05.07.01과 명세 노드의 존재를 확인했으며 앱의 전체 수신 조회·읽음 저장·실패·새 알림 재활성화는017 구현/검증 범위다. 픽셀·색상 대조와 실제 앱 동작 검증은 별도다.

공지 팝업 개선·공지 관리 삭제 동작 추가 시안은 사용자 승인을 마쳤다. [현재 시안 사진](./figma/assets/announcements-licenses-2026-10-06/review.html) · [현재 번호표](./screen-numbering.md).

운동 표시줄의 적용 범위·위치·UI 겹침 허용은 [운동 명세](./workout-recording-spec.md#기록-화면의-운동-중-표시줄)에 확정돼 있다. 별도 배치 결정이나 사용자 재검토를 요구하지 않는다. 실제 앱에 공통 부품을 적용하고 동작을 확인하는 것은 구현 작업이며 시안 제작 완료와 구분한다.

## 나중에 정할 항목

[운동 기록 명세](./workout-recording-spec.md)의 운동 시작 A·B 선택은 미정으로 유지한다. 현재 제작 대상에서 제외하고 기존 비교안만 보관한다.

가입 크루 없음은 일정 안의 상태로 처리하며 별도 독립 화면을 만들지 않는다. 관리자 웹은 모바일과 구분한다. 현재 시안과 검증 자료는 [Figma 현재 작업](./figma/README.md)을 따른다.

새 제작 작업이 생기면 이 목록에 추가한다. 실제 제작·검증 여부는 [디자인 시스템 규칙](./figma-design-system.md)에 맞춰 기록한다.
