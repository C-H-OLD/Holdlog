# 앞으로 만들 화면 목록

정리일: 2026-10-06

제작한 항목과 제작 이력은 이 목록에 다시 넣지 않는다. 최신 요청에 따라 아래 적용 작업이 남아 있다.

## 남은 제작·적용

- 운동 중 표시줄을 기록 화면의 같은 위치에 적용하고 상세·선택창·하단 버튼의 배치를 확인한다. 달력·도장과 표시줄의 겹침은 허용한다. 현재 실제 배치는02.01.01 달력과02.02.01 목록에서 확인했다. 공통 표시줄·고정 영역을 재사용하고 전체 화면을 반복 생성하지 않는다.

## 사용자 검토 대기

## 나중에 정할 항목

- [운동 기록 명세](./workout-recording-spec.md)의 운동 시작 A·B 선택은 사용자가 나중에 정하기로 했다. 현재 확인·제작 대상에서 제외하고 기존 비교안만 보관한다.

가입 크루 없음은 일정 안의 상태로 처리하며 별도 독립 화면을 만들지 않는다. 관리자 웹은 모바일과 구분한다. 현재 시안과 검증 자료는 [Figma 현재 작업](./figma/README.md)을 따른다.

제작·검증은 [디자인 시스템 규칙](./figma-design-system.md)을 따른다. 실제 제작·검증한 항목만 남은 목록에서 제외한다.
