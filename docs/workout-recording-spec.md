# 운동 중 빠른 기록

갱신일: 2026-10-06

## 운동 기록 흐름

- 기존 개인 기록 작성과 함께 운동 중 완등 개수를 바로 기록하는 방법을 제공한다.
- 시작 전에 암장을 선택하고 시작 시각을 저장한다. 운동 중 암장 변경과 새 운동의 중복 시작은 불가하다.
- 난이도별로 색상·이름과 ‘− / 개수 / +’를 한 줄에 표시한다. 개수는1씩 바뀌며0일 때 감소 버튼은 비활성이다.
- 시안은 흰색·노랑·주황·초록·파랑·빨강·핑크·보라·회색·갈색·검정11개를 사용한다. 실제 이름·개수·순서는 선택한 암장의 브랜드 설정을 따른다.
- 운동 종료를 누르면 암장·시작 시각·완등 개수로 개인 기록을 자동 저장한다. 컨디션·사진·영상·후기는 기존 수정 화면에서 추가할 수 있다.
- 종료하지 않고 사용자가 앱을 강제로 끝내면 운동을 취소하고 기록을 저장하지 않는다. 화면 이동·백그라운드 전환은 운동을 유지한다.
- 사용자 강제 종료와 운영체제의 프로세스 정리를 구분하는 방법은 구현 때 확인한다.
- 크루 방문에 자동 연결하지 않는다. 개인 기록 변경 이력은 남기지 않는다.

## 기록 화면의 운동 중 표시줄

- 기록 영역에서만 암장·지난 시간을 표시한다. 누르면 운동 화면으로 돌아간다. 다른 영역에서는 표시줄을 숨기지만 운동은 계속된다.
- 하단 메뉴 위24 간격에 고정한다. 하단 메뉴가 없는 기록 화면에서도 같은 위치를 유지한다.
- **기록 달력에서는 달력·도장과 겹침을 허용한다.** 달력 크기를 줄이거나 표시줄용 여백을 추가하거나 화면 높이를 늘리지 않는다.
- 달력·목록 시안은390×844, 표시줄은(20,709),350×52다. 하단 메뉴·선택창의 조작은 가리지 않는다.

## 공통 운동 알림

Android 진행 중 알림과 iOS 잠금 화면 Live Activity의 내부 구성을 통일한다. 운영체제별 바깥 틀은 구현 때 맞춘다.

| 위치 | 내용 |
|---|---|
| 위쪽 | Holdlog |
| 본문 | 운동 중 → 암장 이름 |
| 아래 왼쪽 | 시계 아이콘·운동 시간·지난 시간 |
| 아래 오른쪽 | 완등 아이콘·완등·합계 |

양쪽 제목·숫자의 높이를 맞춘다. ‘이어서 기록’, +·− 버튼과 다이내믹 아일랜드 표시는 넣지 않는다.

## 운동 시작 진입 · 미확정

시작 방식 A·B는 나중에 정한다. [대안 비교 기록](history/decisions/workout-start-options.md)에서 필요할 때 확인하며, 확정되지 않은 시작 버튼·선택창을 구현 요구사항으로 사용하지 않는다. 암장 선택은 기존03.02 검색만 화면을 재사용할 수 있다.

## 완료 확인 기준

아래는 구현 후 확인할 기준이며 실제 테스트 결과가 아니다. 시작 방식은 확정 후 별도로 확인한다.

| 항목 | 확인할 결과 |
|---|---|
| 개수 조절 | +·−로1씩 바뀌고0 아래로 내려가지 않음 |
| 운동 종료 | 암장·시작 시각·완등 개수로 개인 기록 저장. 반복 요청으로 중복 기록을 만들지 않음 |
| 화면 이동·백그라운드 | 운동이 유지되고 기록 영역에서만 표시줄이 나타남 |
| 사용자 강제 종료 | 종료 버튼 없이 앱을 강제로 끝내면 취소하며 개인 기록은 저장하지 않음. OS 프로세스 정리와 구분하는 구현을 기기에서 확인 |
| 암장 변경·중복 시작 | 진행 중 변경과 새 운동 시작을 막음 |
| 달력 표시줄 | 기존 달력·높이를 유지하고 도장과의 겹침 허용. 메뉴 조작은 유지 |
| 공통 알림 | Android·iOS에서 확정한 정보 배치. +·−·이어서 기록·다이내믹 아일랜드 없음 |
| 기록 연결 | 자동 크루 연결·개인 변경 이력이 생기지 않음 |
