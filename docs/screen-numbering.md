# 화면·상태 번호표

정리일: 2026-10-06

**섹션 → 화면 → 상태** 순서로 찾는다. 예: `02 기록 → 02.01 기록 달력 → 02.01.01 기본`. 번호 변경은 화면 내용이나 제작 범위를 추가하지 않는다.

## 화면 번호

독립 화면의 이름·화면 설계·기본 Figma 링크는 [현재 화면 목록](./screens.md)에서 관리한다. 이 문서는 각 화면의 상태 번호와 Figma 노드를 관리한다.

현재 모바일41개 독립 화면·88개 상태·41개 옆 명세, 관리자 웹3개 독립 화면·5개 상태·3개 옆 명세다. 가입 크루 없음은 일정의01.01.02 상태이며 별도 독립 화면이 아니다.

- 새 링크는 `screen-design.md#screen-섹션-화면` 형식을 쓴다. 제목을 다듬어도 주소는 유지한다.
- 기존 문서 제목으로 만든 링크는 화면 설계서의 별도 주소로 이어진다. 과거 이미지 파일명·Figma 노드 ID·검증 JSON은 바꾸지 않는다.
- 화면 안의 버튼·도장·카드 변형은 공통 부품 규칙으로 관리하며 화면 상태 번호에 포함하지 않는다.

공통 알림은 번호 없는 부품 견본이며 표시줄은 기록 달력02.01.01·목록02.02.01에 배치했다. 제작·검증 자료는 [현재 Figma 자료](./figma/README.md)에서 확인한다.
