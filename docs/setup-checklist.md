## 4. 첫 구현과 확인

서비스 관리자 암장·세팅 등록 → 로그인·크루 생성·가입·관리자 이관 → 5개 메뉴 → 일정 → 개인·공동 방문 → 암장 지도·추천 → 통계·알림 순서를 기본안으로 삼는다. 기술과 제품 정책은 확정됐으며, 실제 구현 순서는 기능 간 선행 작업에 맞춰 조정한다.

- [ ] 기능 명세 9절의 T 시나리오로 기능별 완료 확인
- [ ] [운동 기록 명세](./workout-recording-spec.md)의 개수 조절·종료 자동 저장·강제 종료 취소·기록 표시줄·공통 알림 구현 및 기기 검증. 시작 방식 결정은 별도
- [ ] 지도 검색·상세 복귀, 위치 권한 거절 후 검색 유지 확인
- [ ] 크루별 접근 제한, 개인 변경 이력 미저장·메뉴 없음, 일정·크루 방문 이력의 권한 확인
- [ ] 연결 전후 중복 집계 방지, 공동 방문 삭제 후 개인 기록·미디어·진행 중 업로드·변환 보존 확인
- [ ] 개인 기록 삭제 시 해당 본인 첨부 파일 삭제와 실제 참석 유지, 계정·파일 자체 삭제 시 대상 파일 정리 확인
- [ ] 저장 실패 시 입력 유지와 재시도 확인

개발 환경을 구성하고 실제 실행을 확인한 뒤 설치 명령과 실행 방법을 추가한다.
