# Holdlog(가제) — 미결정 사항

다음 제품 결정이 남아 있다.

- 운동 시작 A·B 중 사용할 방식은 사용자가 나중에 정하기로 했다. 현재 작업에서 제외하고 비교안만 보관한다. 암장 선택은 기존 검색만 화면을 재사용할 수 있으며 새 화면 누락을 뜻하지 않는다.

- 수신 알림 목록의 개별 알림 열기와 읽음 전환 관계, 푸시/종류별 설정과 목록 생성 관계는 이번 확정 표에 포함되지 않았다. [002 추가 계약 범위](../specs/002-shared-contracts/contracts/README.md#수신-알림-목록-추가에-따른-남은-계약)에서 후속 결정한다. 전체 크루 목록·모두 읽음·읽음 저장/실패는 [확정 규칙](./functional-spec.md#notification-inbox)을 유지한다.

새로운 결정이 필요한 경우에만 이 문서에 추가하고, 결정되면 해당 명세로 옮긴다. 확정된 제품 동작은 [기능 명세](./functional-spec.md), 기술 선택은 [기술·운영 명세](./technical-spec.md), 실제 설정·구현·검증 작업은 [초기 설정 준비](./setup-checklist.md)에서 관리한다.
