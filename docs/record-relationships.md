# 크루 방문·개인 기록·첨부 파일의 관계

갱신일: 2026-10-02. [현재 제작 화면](./screens.md)과 사용자가 확정한 동작을 기준으로 한다.

크루 방문은 함께 운동한 사실을 담고, 개인 기록은 각자의 운동 내용을 담는다. 크루 방문 상세는 개인 기록을 연결해서 보여준다. 표시와 소유권을 구분하며, 공동 정보 변경으로 개인 기록을 덮어쓰지 않는다.

등록·연결 흐름과 B01~B05는 확정 사항이다. 개인 통계는 본인이 저장한 개인 기록만 집계한다. 개인 파일은 기본 공개·파일별 비공개 선택이며(D03), 개인 기록의 활성 공동 연결은 최대 하나다(D06).

## 1. 어디에서 무엇을 등록하는가

일정·공동 방문·개인 방문은 날짜·시간을 필수로 입력하고 UTC 시점과 입력 시간대를 보존한다. 각 기기는 자기 시간대로 표시한다. 크루에서 개인 기록을 작성할 때 공동 방문 시각을 미리 채우며 실제 저장은 본인이 한다. 시간 누락 상태는 저장하지 않는다.

| 화면 | 등록·처리하는 것 | 담당 |
|---|---|---|
| 크루 방문 등록 | 날짜·시간·암장·실제 참석자·공동 메모·공동 공유 파일 | 해당 크루원 |
| 크루 방문 상세 → 본인 참석자 행 → 새로 작성 | 내 운동 내용과 첨부 파일. 날짜·암장은 선택한 방문으로 고정 | 본인 |
| 크루 방문 상세 → 본인 참석자 행 → 기존 기록 선택 | 같은 날짜·암장의 기존 본인 개인 기록 선택 | 본인 |
| 개인 기록 등록 | 본인 날짜·시간·암장·운동 내용·파일 | 본인 |


**개인 기록 연결은 크루 방문 상세의 본인 참석자 행에서만 시작한다. 개인 기록 상세에는 연결 메뉴를 두지 않는다.**

### 기본 흐름: 크루 방문부터 등록

1. 민수가 A암장 크루 방문을 만들고 민수·지연을 참석자로 등록한다.
2. 이때 두 사람의 실제 참석만 저장한다. 개인 기록을 자동 생성하거나 최초 연결하지 않는다.
3. 지연이 그 방문의 참석자 목록에서 본인 행을 누르고 다이얼로그에서 새로 작성을 선택한다. 날짜·암장은 해당 방문으로 고정한다.
4. 지연이 운동 내용과 파일을 입력하고 저장하면 개인 기록 생성과 연결이 함께 완료된다. 화면을 열었다가 나가면 기록은 생기지 않는다.
5. 이미 같은 날짜·암장의 개인 기록이 있으면 후보를 확인해 ‘기존 기록 연결’을 선택할 수 있다. 후보 하나라도 임의로 연결하지 않는다.

### 개인 기록을 먼저 저장한 경우

1. 지연이 자신의 운동 기록을 먼저 저장한다.
2. 본인이 실제 참석자로 등록된 같은 날짜·암장의 크루 방문 상세로 이동한다.
3. 본인 참석자 행을 누르고 다이얼로그에서 기존 기록 선택을 고른 뒤 같은 날짜·암장의 본인 기록을 선택한다.
4. 같은 개인 기록 ID를 연결한다. 내용을 복사하거나 완등 개수를 합산하지 않는다.

본인이 실제 참석자로 등록되지 않았다면 연결 후보에 나타나지 않는다. 참석 사실을 먼저 확인·등록하며 연결 화면이 참석을 임의로 만들어 주지 않는다. 같은 날 같은 암장의 별개 방문은 자동 병합하지 않는다.

## 2. 소유권과 관계

| 대상 | 직접 보관하는 정보 | 관리 권한 |
|---|---|---|
| 크루 방문 | 크루, 방문 날짜·암장, 공동 메모, 선택적 일정 연결 | 해당 크루원 수정, 관리자 삭제. 날짜·암장은 연결 제한 적용 |
| 실제 참석 | 어느 공동 방문에 누가 실제로 왔는지 | 해당 크루원이 관리. 개인 기록 유무와 별개 |
| 개인 기록 | 소유자, 본인 날짜·암장, 완등·브랜드 ID·난이도 숫자, 컨디션, 개인 후기 | 본인만 작성·수정·삭제 |
| 개인 기록 연결 | 공동 방문의 참석자와 개인 기록 ID의 관계 | 최초 연결과 새 작성은 본인. 유효한 이전 연결의 재사용은 기존 재참석 규칙 적용 |
| 첨부 파일 | 업로더, 개인 기록 첨부 관계, 파일·썸네일·변환본 | 업로더 소유 |
| 공동 파일 공유 | 어느 파일을 어느 공동 방문에서 보여줄지 | 소유권 이전 없이 공유 관계로 관리. 타인 파일에 대한 관리자 특별 숨김·삭제 권한은 현재 제공하지 않음 |

자동 재연결은 참석자 제외로 끊긴 직전 연결에만 적용한다. 본인의 직접 연결 해제·크루 탈퇴·개인 기록 삭제가 발생하면 이전 참조만으로 다시 공개하지 않는다. 다시 연결하려면 본인이 선택하며, 일반 재참석에서도 소유권·날짜·암장·현재 가입·다른 활성 연결·삭제 여부를 확인한다.

공동 방문에 직접 올린 파일도 업로더 소유다. 불참자가 공동 파일을 올려도 참석 사실이나 개인 방문을 자동 생성하지 않는다.

개인 기록은 공동 방문 없이도 존재한다. 공동 방문 역시 개인 기록 없이 실제 참석 사실만 가질 수 있다. 개인 기록 하나는 최대 하나의 공동 방문에만 활성 연결한다(D06 확정). 다른 방문 연결 중인 기록은 후보로 선택할 수 없으며 재연결 시 소유자·날짜·암장·권한·삭제 여부를 확인한다.

## 3. 종속 방향

| 방향 | 의미 |
|---|---|
| 크루 방문 상세 → 연결된 개인 기록 참조 | 화면이 원본 개인 기록을 읽는다. 개인 내용을 복사해 별도 관리하지 않음 |
| 크루 방문 상세 → 접근 가능한 파일 참조 | 표시할 파일의 소유권·공유 권한을 확인. 파일 복사나 소유권 이전 없음 |
| 개인 기록 수정 → 크루 상세 표시 갱신 | 본인이 바꾼 완등·컨디션 등이 같은 원본을 통해 표시됨 |
| 개인 기록 삭제 → 본인 첨부 파일 삭제 | B02 확정. 같은 파일의 공동 공유도 해제 |

**공동 방문 수정 → 개인 기록 자동 수정**, **공동 방문 삭제 → 개인 기록·파일 삭제** 방향은 없다. 개인 기록 삭제가 공동 방문이나 실제 참석을 지우지도 않는다.

방문 시점·암장은 양쪽에 저장되지만 자동 동기화하지 않는다. 대신 연결할 때 같은 값인지 검사하고, 연결 중에는 변경을 제한하여 서로 다른 암장의 기록이 섞이지 않게 한다.

## 4. 날짜·암장의 일치와 수정 제한 — B01

이 문서의 날짜 고정·수정 제한은 공동 방문에 저장한 시간대의 날짜를 뜻한다. 연결된 개인 기록의 날짜 입력은 비활성·자물쇠로 표시하고 암장 변경도 막는다. 시간 입력은 공동 방문 저장 시간대의 같은 날짜 안에서만 허용하며 기기 표시 날짜는 시간대 변환 결과를 따른다. 제한 설명 문구는 폼에 반복 표시하지 않는다.

- 최초 연결·재연결·크루 방문에서 개인 기록 생성 시 본인 소유권, 크루 접근 권한, 실제 참석, 같은 날짜·암장을 검사한다.
- 개인 기록이 하나라도 연결된 공동 방문은 날짜·시간·암장을 바로 바꿀 수 없다. 공동 메모와 참석자는 기존 권한대로 관리한다.
- 공동 방문의 저장 시간대에서 같은 날짜를 유지하는 개인 시간 수정은 본인에게 허용한다. 날짜가 바뀌거나 암장을 바꾸려면 먼저 연결을 해제한다. 화면과 서버가 같은 기준을 검사하며 개인 시간 수정으로 공동 시각은 바뀌지 않는다. 연결된 개인 기록은 암장을 바꿀 수 없다. 완등·컨디션·후기·파일은 본인이 수정할 수 있다.
- 잘못된 방문에 연결했다면 본인이 연결을 해제하고 올바른 방문을 선택한다. 개인 날짜·암장이 틀렸다면 해제 후 본인이 수정한다.
- 연결이 없는 공동 방문의 날짜·암장은 기존 권한으로 수정한다. 다른 사람의 연결을 강제로 일괄 해제하고 날짜·암장을 변경하는 동작은 제공하지 않는다.
- 다른 암장에서 운동한 사람은 별도 방문에 기록한다.
- 연결 해제·참석자 제외·공동 삭제 시 개인 날짜·암장·운동 내용·파일은 이미 저장된 값을 그대로 유지한다. 공동 값을 덮어쓰지 않는다.

개인 기록을 분리한 뒤 본인이 암장을 바꿔 난이도 체계가 달라진다면 기존 개수·브랜드 ID·난이도 숫자를 보존하고 본인이 확인한다. 다른 브랜드의 같은 색상으로 자동 변환하지 않는다.

크루 방문을 삭제한 뒤에는 같은 날짜에 새 방문을 작성할 수 있고, 기존 일정에서도 새 크루 방문을 작성할 수 있다. 새 방문은 새 기록으로 저장하며 삭제된 방문을 복구하거나 보존된 개인 기록을 자동 연결하지 않는다. 개인 기록은 본인이 다시 선택해 연결한다. 일정 종료와 최초 방문 생성 사실은 유지하며 21시 기록 요청을 다시 보내지 않는다.

## 5. 크루 방문 상세의 표시

| 상태·영역 | 표시와 동작 |
|---|---|
| 공동 정보 | 공동 방문의 날짜·암장·메모 |
| 실제 참석자 | 개인 기록이 없거나 삭제돼도 참석 표시는 유지 |
| 내 기록 미연결 | 해당 공동 방문에 개인 기록이 연결되지 않은 참석. 본인 이름 아래 ‘연결된 기록 없음’과 행 오른쪽 화살표를 표시하고 행 선택 시 새로 작성 / 기존 기록 선택 다이얼로그 제공. 개인 통계에 추가하지 않음 |
| 본인이 저장했지만 운동 내용 미입력 | 실제 개인 기록은 존재. 완등·컨디션은 ‘미입력’, 0으로 만들지 않음 |
| 개인 기록 연결 완료 | 같은 원본에서 공개 가능한 완등·컨디션 요약 표시. 본인은 S12, 타인은 해당 방문의 회원 기록 상세02.11.01(S13)로 바로 이동하며 회원 전체 목록을 거치지 않음 |
| 사진·영상 | 접근 가능한 파일만 표시하며 같은 파일은 중복 표시하지 않음. 업로더 정보는 권한 판단에 사용하며 썸네일 옆에 이름을 추가하지 않음 |

‘연결 대기’라는 별도 승인 상태는 없다. 개인 기록을 자동으로 만들어 빈 상태를 표시하지 않는다. 본인이 저장한 기록에서 일부 운동 값을 입력하지 않은 것은 허용된 입력 정책에 따른 별개 상태다.

미디어 첨부는 기록에 새로 업로드하는 방식이다. 앱에 올라간 파일을 선택해 다른 기록에 다시 첨부하거나 옮기는 동작은 없다. 개인 기록과 크루 방문의 연결로 첨부를 함께 조회하는 기존 관계는 유지한다.

개인 미디어는 파일별 공개 / 비공개를 선택하고 후기도 별도 공개 값을 가진다(D03). 공개 파일은 해당 기록이 연결된 크루의 활성 회원에게만 보인다. 연결 전과 다른 가입 크루에서는 본인 외에는 볼 수 없다. 비공개는 본인만 보며 개인 사진의 공개·비공개는 아이콘으로 표시한다. 크루 방문 상세의 공유 사진에는 공개·비공개 아이콘이나 추가 버튼을 두지 않는다. 비공개 전환 시 저장본·썸네일·공유 접근도 차단한다. 인터넷 전체 공개가 아니다.

공동 방문에 직접 올린 파일은 해당 크루 범위의 공유 파일이다. 다른 소속 크루에는 개인 공개 수치만 보이며 사진·영상·후기와 원래 크루의 공동 정보는 공개하지 않는다. 분리된 본인 전용 기록·파일은 기본 공개로 되돌리지 않는다. 연결된 개인 기록은 본인이 공개를 선택한 사진·영상·후기만 해당 크루원에게 표시한다. 계정 전체 개인 통계는 본인만 보며 회원 화면의 통계는 조회 가능한 기록만 집계한다. 개인 변경 이력은 저장하지 않는다.

## 6. 수정·삭제 영향표

| 작업 | 공동 방문·참석 | 개인 기록 | 파일 |
|---|---|---|---|
| 크루 방문 등록·새 참석자 추가 | 방문·참석 저장 | 자동 생성·최초 연결 없음 | 공동에 직접 올린 파일만 처리 |
| 본인이 크루에서 개인 기록 작성·저장 | 해당 참석에 연결 | 새 개인 기록 생성. 날짜·암장 고정 | 본인 첨부로 저장, 공개는 별도 정책 |
| 본인이 기존 개인 기록 연결 | 같은 날짜·암장의 본인 참석에 연결 | ID·내용 유지 | 소유권 유지 |
| 공동 날짜·암장 수정 시도 | 개인 연결이 있으면 거절, 없으면 권한에 따라 수정 | 자동 변경 없음 | 영향 없음 |
| 공동 메모 수정 | 메모만 변경 | 영향 없음 | 영향 없음 |
| 본인 완등·컨디션 수정 | 개인 항목의 표시 갱신 | 같은 원본 수정 | 영향 없음 |
| 본인이 연결만 해제 | 공동 방문·실제 참석 유지, 연결 제거 | 기존 값 보존, 본인 전용 전환 | 개인 파일 보존 |
| 참석자 제외 | 해당 참석·개인 연결 제거 | 기존 값 보존, 본인 전용 전환 | 개인 파일 보존 |
| 공동 방문 삭제 | 공동 방문·참석·연결·해당 공유 제거 | 기존 값 보존, 본인 전용 전환 | 업로더 보관함에 보존. 불참자 파일도 보존 |
| 본인이 개인 기록 삭제 | 공동 방문·참석 유지, 개인 연결 제거 | 본인 기록 삭제, 자동 재생성 없음 | 해당 기록의 본인 첨부 파일·공유 삭제 |
| 본인이 파일 자체 삭제 | 해당 파일 표시 제거 | 기록·운동 내용 유지 | 파일·썸네일·변환본·공유 삭제 |
| 파일 공유만 해제 | 해당 방문의 표시 제거 | 영향 없음 | 본인 파일 유지 |

개인 기록과 무관하게 공동 방문에 직접 올린 파일과 다른 사람의 파일은 개인 기록 삭제 대상이 아니다.

공유 처리의 구현 기본안: 분리되는 개인 기록에서 공유한 파일은 해당 방문의 공유도 해제하고, 개인 기록과 무관하게 공동 방문에 직접 올린 파일은 참석 여부에만 의존하지 않는다. 파일별 공개·비공개는 D03 확정 정책을 적용한다.

## 7. 서버에서 반드시 검사할 것

- D05: 글·운동 수치와 파일 업로드를 분리한다. 일부 파일 실패는 저장된 기록·성공 파일을 지우지 않고 해당 파일만 재시도한다. 브랜드 ID·난이도 숫자·완등 개수를 보존하며 색상은 현재 매핑을 사용한다.
- D08: 내 기록·개인 통계·보관함은 계정 전체이며 크루 전환으로 필터링하지 않는다. 공동 방문·일정·회원의 크루 범위와 구분한다.

- 크루 방문의 새로 작성 / 기존 기록 선택에 같은 연결 검사를 사용한다. 본인 소유권·크루 소속·실제 참석·날짜·암장 일치를 저장 직전에 확인한다. 개인 상세에서 새 연결을 시작하는 경로는 없다.
- 공동 날짜·암장 수정과 개인 연결이 동시에 와도 서로 다른 값의 연결을 저장하지 않는다.
- 크루에서 시작한 개인 기록 생성과 연결은 함께 성공하거나 실패한다. 화면 진입·참석 추가·요청 재시도만으로 빈 기록·중복 기록을 만들지 않는다.
- 개인 기록·파일의 권한은 호출한 화면이 아니라 소유자로 판단한다. 크루 상세에서 보인다고 타인 편집 권한을 주지 않는다.
- 공동 방문 삭제가 개인 기록·파일의 자동 삭제로 이어지지 않게 한다.
- 개인 기록 삭제 시 연결 제거·파일 접근 차단을 함께 처리한다. 실제 저장 파일 삭제 실패는 재시도하고 삭제된 파일을 보관함에 되살리지 않는다.
- 개인 기록·개인 첨부 파일의 변경 이력과 개인 과거 값은 저장하지 않는다. 공동 기록에 남기는 최소 삭제·연결 해제 사건에는 개인 후기·완등·컨디션 등 개인 내용을 넣지 않고 계정 삭제 시 작업자 표시를 익명화한다.
- 늦게 완료된 업로드나 동시 공동 방문 삭제가 개인이 지운 파일·기록을 복원하지 못하게 한다.
- 실제 테이블·API 이름은 기술 설계에서 정한다. 이 문서는 논리 관계와 영향 범위의 기준이다.

## 8. 개인 통계 — B03 확정

개인 통계는 본인이 저장한 개인 기록만 집계한다. 날짜·시간·암장만 저장해도 방문1회로 세며 참석만 등록된 건은 제외한다. 기존 기록을 연결해도 횟수는 늘지 않는다. 개인 기록 삭제는 해당 통계에서 제외하며 실제 참석은 유지한다. 상세 집계는 [기능 명세 5.3절](./functional-spec.md#53-통계-계산)을 따른다.

제품 범위는 [PRD](./prd.md), 화면 동작은 [기능 명세](./functional-spec.md), 기술·운영 기준은 [기술·운영 명세](./technical-spec.md)를 참고한다.
