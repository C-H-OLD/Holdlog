# 문서 역할 분리 · 2026-10-06

## 요청과 근거

사용자는 개발에 필요한 현재 기준을 한눈에 찾고, 개인 응답 취향과 과거 논의·검증 기록은 프로젝트의 주요 문서에서 분리하기를 요청했다.

[OpenAI의 하네스 엔지니어링 글](https://openai.com/index/harness-engineering/)은 짧은 AGENTS.md를 목차로 쓰고 상세 기준은 구조화한 문서에 두며, 계획·결정 기록을 따로 관리하고 링크·구조를 검사하는 방식을 설명한다. Holdlog에는 이 원칙을 적용하되 해당 글의 폴더 구조나 모든 도구를 그대로 복제하지 않는다.

## 적용

- AGENTS.md는 작업별 기준 문서로 안내하는 목차로 바꿨다. 기존 Figma 규칙은 디자인 시스템에서 계속 관리한다.
- 한국어·쉬운 설명 규칙은 사용자 로컬 AGENTS.md에 이미 있어 프로젝트에서 제거했다. 로컬 파일은 수정하지 않았다.
- 루트 README는 프로젝트 소개·현재 단계·개발 시작 링크만 관리하고 상세 규칙은 기준 문서에 남긴다.
- 개발 시작 안내를 추가하고 문서 관리 규칙은 work-rules.md로 모았다.
- 날짜별 Figma 보고서·이전 계획·시안 생성 기록을 history/로 옮겼다. 사진·공통 부품 원본·현재 상태 자료는 기존 위치에 유지했다.
- state.json의 과거 작업 필드는 별도 전체 스냅샷에 보존하고 현재 페이지·부품·화면·검증 범위는 유지했다.
- 기존 링크를 갱신하고 문서 링크·JSON·화면 번호 검사 도구를 추가했다.

현재 유지할 규칙은 [프로젝트 작업 규칙](../../work-rules.md), 실제 시작 위치는 [개발 시작 안내](../../development.md)를 따른다.
