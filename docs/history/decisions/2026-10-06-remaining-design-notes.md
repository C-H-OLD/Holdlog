# 남은 화면 설명의 과정 기록 · 2026-10-06

아래는 현재 명세에서 분리한 당시 설명이다. 현재 모양·동작의 기준은 [화면 설계](../../screen-design.md)다. 내 참석 우선 정렬 제안은 확정 규칙으로 사용하지 않는다.

- 15·16·17일과 그 아래 22·23·24일에 일정을 배치한 간격 비교용 예시다. 기존 시안의 가운데16일은 일정3개다. 2026-10-01 마무리 화면은16일 일정4개(점1개 +3),23일 일정2개(점2개),24일 암장미정 예시를 사용한다. 01.02·01.03의 29·30일 예시와는 다른 데이터다. 실제 앱에서 달력·목록·시트는 같은 월·필터·일정 데이터를 사용한다.

**01.02 참석 응답 표시 · 2026-09-30 사용자 수정:** 내가 참석으로 응답한 일정은 연한 보라색 항목 배경과 `참석` 글자 배지로 함께 표시한다. 여기서 참석은 일정에 대한 참여 의사이며 실제 방문 출석을 뜻하지 않는다. 미응답·불참은 중립 배경이다. 첫 항목·내일·암장 지점이라는 이유로 강조하지 않는다. Figma 예시의 9월 30일 첫 `암장 미정 · 19:30`은 내 응답을 미응답에서 참석으로 바꾸고, 총 4명 중 `참여 3명 · 불참 1명 · 미응답 0명`으로 맞춘다. 위 생성 이미지는 변경 전 자료이므로 이 최신 설명을 우선한다.

**01.03 디자인 변경 · 2026-10-01 사용자 확정:** 일정이 있으면 선택한 3안을 따른다. 모든 항목의 배경은 흰색이고, 제목 → 시간 → 내 응답 → 전체 응답 인원 순으로 별도 줄에 표시한다. 참석은 보라색 체크와 ‘내가 참석해요’, 불참은 코랄색 ×와 ‘내가 불참해요’, 미응답은 회색 빈 원과 ‘아직 응답하지 않았어요’다. 01.02 목록의 참석 배경 규칙은 유지한다. 빈 날짜는 선택한 1안처럼 중앙 달력 그림·‘이 날짜에 일정이 없어요’·‘함께할 일정을 만들어 보세요.’를 묶는다. 너비390, 최대2개 표시와 내부 스크롤을 지킨다. 미응답 예시는 별도 전체 화면을 만들지 않고 같은 바텀시트 인스턴스만 복사한다. 예시에서 내가 참석을 미응답으로 바꾸면 첫 항목 인원은 참여2·불참1·미응답1로 함께 바뀐다.

- 대표 도장은 내 참석 방문을 먼저 보여주는 것을 제안한다. 여러 후보의 상세 정렬은 구현 설계에서 일관된 기준으로 정한다.

기존 [02.01.02 기록 없음](https://www.figma.com/design/vla4pXPo8FaCWFXfpIbYzx/Holdlog?node-id=424-7217)은9월1~2일을 적용해 기록이 없는 예시로 사용한다. 기존 [02.02.02 필터 적용](https://www.figma.com/design/vla4pXPo8FaCWFXfpIbYzx/Holdlog?node-id=424-6805)은 피크 성수 조건을 적용한 예시다. 별도 화면을 복제하지 않았다. - 2026-10-02 코멘트 반영: 기본 Google 계정 시안을 유지하고 [Apple 계정 칸 견본](https://www.figma.com/design/vla4pXPo8FaCWFXfpIbYzx/Holdlog?node-id=529-31281)을 옆에 배치했다. 같은 Account/Identity 원본을 사용하며 제공자 아이콘은 모두32×32 영역이다. 전체 화면·상태 번호는 추가하지 않는다. [수정 후 사진](../../figma/assets/apple-account-2026-10-02/apple-account.png).

**동일 일정 데이터 반영 · 2026-09-30:** 01.02와 같은 9월 30일 첫 `암장 미정` 일정은 `19:30 · 참석 · 참여 3명 / 불참 1명 / 미응답 0명`으로 표시한다. 위 생성 이미지의 변경 전 문구보다 이 최신 값을 우선한다. 두 번째 `그립 연남 · 20:00 · 불참`은 `참여 2명 / 불참 1명 / 미응답 1명`을 유지한다.
