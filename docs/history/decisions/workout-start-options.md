# 운동 시작 방식 비교 · 미확정

## 운동 시작 진입 비교 · 미확정

시작 방식은 나중에 정한다. 비교안은 정식 화면 수에 포함하지 않는다.

| 안 | 진입 흐름 |
|---|---|
| A | 달력·목록의 원형 ▶ → 운동 시작 / 기록 작성 선택창 → 운동 시작 선택 → 암장 선택 |
| B | 제목 아래 ‘지금 운동하기’ 카드 → 암장 선택 → 시작 |

암장 선택은 기존03.02 검색만 화면을 재사용할 수 있다. A안에서 기록 작성의 세부 진입·날짜 처리는 확정 전이다. A안 버튼과6주 달력의 겹침·B안 스크롤은 시작 방식을 고를 때 확인한다.
