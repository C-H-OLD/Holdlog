# 통계·알림 목록 Figma 메타데이터 확인

확인일: 2026-10-07

## 범위와 근거

사용자가 확정한 통계 상단·기간 배치·빈 기간 문구와 수신 알림 목록·모두 읽음 규칙을 현재 문서에 반영하기 위해 Figma 메타데이터를 조회했다. 파일 키는 `vla4pXPo8FaCWFXfpIbYzx`, 화면 페이지는 `6:3`이다. Figma 파일은 수정하지 않았다.

| 확인 대상 | 실제 노드·크기 | 결과 |
|---|---|---|
| 개인 통계 기본 | `471:30692`,390×2095 | 기존04.01.01 유지, 현재 높이 확인 |
| 개인 통계 방문 없음 | `471:31607`,390×844 | 기존04.01.02 유지 |
| 개인 통계 기간 선택 | `507:50415`,390×844 | 기존04.01.03 유지 |
| 알림 목록 기본 | `625:38695`,390×844 | 새05.07.01 확인. 화면 내부는 Notifications/Screen 인스턴스 |
| 알림 화면 옆 명세 | `625:39385` | 새05.07 명세 노드 확인 |

05.07.01의 캔버스 위치는05 내 정보 섹션 안의(60,6609)이다. 내부 메타데이터에서 오늘·어제 묶음, 종류별 알림 행, 시간/읽지 않은 점 영역, Navigation/PageHeader와 Control/MarkAllNotificationsRead를 확인했다. 날짜·사건·크루명 등 시안 예시는 실제 서비스 자료가 아니다.

[현재 통계 설계](../../screen-design.md#screen-04-01)·[알림 목록 설계](../../screen-design.md#screen-05-07)·[확정 수신/읽음 규칙](../../functional-spec.md#notification-inbox)·[현재 번호표](../../screen-numbering.md)로 연결했다. 등록 후 문서·번호·상태 자료는 모바일42개 화면·89개 상태, 웹3개 화면·5개 상태로 일치했다.

## 수행하지 않은 검사

픽셀·색상·정렬의 시각 대조, 앱/서버 수신 목록 조회, 읽음 저장·실패·재진입·새 수신 동작 검사는 수행하지 않았다. 화면/명세 노드의 존재 확인과 사용자 확정 규칙 반영을 제품 구현 완료로 취급하지 않는다. 알림 목록·읽음 API와 Runtime 진입 확장은002의 후속 계약 범위다.

앞선41개 화면 사진·001 완료 검증 기록은 해당 시점의 결과 그대로 보존했다.
