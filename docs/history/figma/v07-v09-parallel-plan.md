# V07~V09 공통 준비와 병렬 제작

사용자 요청: 2026-09-30. 공통 부품을 먼저 확인·등록한 뒤 화면별 서브 에이전트가 병렬 제작한다.

## 공통 준비 단계

- 담당: 기존 Astra 일정 에이전트. 이 단계에서는 화면 조립을 시작하지 않는다.
- 실제 Figma 원본을 먼저 조회하고 모양과 용도가 맞으면 재사용한다.
- 공통 대상: 텍스트·배지·구분선·아이콘·주요 버튼, V08/V09의 뒤로·크루명 상단.
- 등록 후 원본 이름·ID·속성·사용처를 `shared-v07-v09.json`에 기록한다. 아직 등록하지 않은 부품은 완료로 쓰지 않는다.
- V05/V06의 기존 원본과 화면은 보존한다.

## 병렬 단계의 소유권

| 담당 화면 | 수정할 기존 프레임 | 담당자가 새로 만들 수 있는 원본 역할 |
|---|---|---|
| V07 | 123:877, 기존 빈 날짜 123:922 | Sheet용 일정 행, 시트 상자·닫기/손잡이·날짜 제목 묶음, 상태 안내 |
| V08 | 만들기 118:160, 수정 118:242 | 아이콘 입력 행·필드 라벨·설명 입력 영역, 일정 입력 묶음 |
| V09 | 미응답 123:221, 참여 123:278, 불참 123:951 | 장소 정보 행·독립 응답 버튼 상태·회원 명단 행·내 신청 묶음 |

- 공통 레지스트리에 등록된 원본은 병렬 작업 동안 읽기 전용이다. 변경 또는 추가 공통 부품이 필요하면 루트에게 요청한다.
- 화면별 원본은 위 역할의 담당자 한 명만 만든다. 화면 이름만 다른 동일 역할의 중복 원본은 만들지 않는다.
- 새로운 원본 이름은 담당자가 실제 조회 후 보고하고, 같은 이름의 기존 원본이 있으면 우선 검토한다.
- 텍스트·아이콘까지 원본 인스턴스를 사용하며 연결을 끊지 않는다. 필요한 새 원본부터 만들고 화면을 조립한다.
- 각 담당자는 독립 브라우저 탭을 사용한다. 다른 담당자의 탭이나 프레임을 조작하지 않는다.
- 공통 시스템 클립보드를 사용하는 복사·붙여넣기는 동시에 수행하지 않는다. `/tmp/holdlog-figma-clipboard.lock` 디렉터리의 배타적 잠금을 확보한 담당자만 복사→붙여넣기 쌍을 수행하고 즉시 해제한다. 소유자는 `owner.txt`에 기록한다. 일반 DOM 입력과 클립보드를 사용하지 않는 탭 대상 키보드 작업은 각자의 탭에서 병렬 진행한다.
- `state.json`, 디자인 시스템 문서, README, 작업 목록은 루트만 갱신한다. 담당자는 화면별 별도 결과 JSON과 PNG를 저장한다.

- V08 기준: `16-schedule-create.png`. 최신 명세에 따라 시간도 필수, 관련 안내 수정. 같은 입력 구조를 수정 화면에서 재사용한다. 제목·정원 등 새 필드는 추가하지 않는다.

## 버튼 아이콘 상태 · 최신 사용자 확인

2026-09-30 사용자는 “아이콘있는 버튼이라는 상태를 만드는거지”라고 확인했다. 별도 버튼 원본이나 새 주요 색상 스타일이 아니라 같은 Control/Button의 아이콘 유무를 상태로 관리한다. 기존 버튼은 아이콘 없음, V07 생성 동작은 플러스 아이콘 있음 상태를 사용한다. 추가 속성의 기본값은 아이콘 없음으로 두어 기존 사용 화면을 보존한다.

## 병렬 중 루트가 배정한 공통 변경

동일 원본을 두 담당자가 수정하지 않도록 아래 변경은 한 담당자에게만 배정했다. 실제 완료 여부는 레지스트리와 결과 JSON을 따른다.

- V07: 기존 Button 세트에 LeadingIcon=None/Plus 추가. 기존 9상태 None 보존. OnAction 기존 색상 값은 그대로 두고 Stroke 사용 범위 추가.
- V09: 기존 Avatar 세트에 SmallSelf/SmallMember 추가와 공통 회색 표면 변수 2개 등록. 기존 Small/Large·기존 Avatar 색상 보존.
- V09: 같은 DateBadge에 Default/Compact 크기 상태 추가. 기존 Default43×24는 보존, 나 배지는 Compact28×24. V08은 Default 사용.
- V09: 응답 버튼의 높이40 전용 변수는 기존 같은 값·용도 검색 후 없을 때 추가. 주요 동작 버튼52는 보존. 작은 원본들을 합친 ScheduleDetail 원본은 기존 세 화면에서 재사용.
- V08: FilledMapPin은 기존 같은 역할 검색 후 없을 때 직접 SVG 원본으로 추가. PickerRow의 암장 아이콘에 사용.
- V08: Primary 기존 값 유지·Stroke 적용 범위 추가가 필요하면 담당하고 SubpageBar 뒤로 인스턴스만 해당 색상 연결. 다른 전역 아이콘 원본 색상은 유지.

공통 변경 권한은 위 용도와 노드에만 적용하며 원본 연결 해제나 화면별 스타일 덮어쓰기를 허용하지 않는다.
