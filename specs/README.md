# 기능 스펙 목록

GitHub Spec Kit을 사용하며 `spec.md`는 Living Spec으로 유지한다. 동작을 바꾸면 기존 스펙을 갱신한다. 개발 절차·선택 방법은 [개발 흐름](../docs/development-workflow.md)을 따른다.

| 범위 | 원본 스펙 | 상태 |
|---|---|---|
| 개발 기반 구성 | [001-development-foundation](001-development-foundation/spec.md) | 명세 작성·품질 확인 완료. 설계·구현 전 |

제품 기능은 아직 기존 [기능 명세](../docs/functional-spec.md)와 [공통 기록 관계](../docs/record-relationships.md)가 원본이다. 개발하는 기능부터 범위를 정리하며 원본을 옮긴 경우 기존 문서는 해당 스펙으로 연결한다. 스펙 번호는 화면 번호·S·D·B·T 번호와 별개다.
