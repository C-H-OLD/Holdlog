# 공통 계약 작업 안내

이 파일은 계약 원본·생성물 변경 작업의 기준 문서를 찾는 목차다. 루트의 [공통 안내](../../AGENTS.md)와 [작업 규칙](../../docs/work-rules.md)을 함께 따른다.

| 작업 | 먼저 읽을 문서 |
|---|---|
| 모든 계약 작업·공개 진입점·생성·소비 검사 | [계약 패키지 안내](README.md) · [공통 아키텍처](../../docs/architecture.md#의존-방향) |
| HTTP·runtime 형식과 처리 의미 | [사용 규칙](conventions.md) · [계약 설계 범위](../../specs/002-shared-contracts/contract-scope.md) |
| 권한·소유·원자 변경·잠금 | [논리 모델](../../specs/002-shared-contracts/data-model.md) · 해당 기능 스펙의 원본 연결 |
| 원본·버전·예제·생성 도구 변경 | [개발자 배정 기준](../../specs/development-roles.md#여러-개발자의-작업-배정) · [착수 준비 대조](../../specs/002-shared-contracts/contract-readiness.md) |
| 기능 계획·이슈·PR·완료 확인 | [개발 흐름](../../docs/development-workflow.md) · [기능 스펙 목록](../../specs/README.md) |

생성물 수기 수정과 앱 구현의 계약 패키지 유입을 피하기 위해 이 위치에도 작업 안내를 둔다. 상세 규칙·명령은 위 원본에서 관리한다.
